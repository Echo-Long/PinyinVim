## V0.3.0 — 2026-10-12

收敛正式构建、测试、启动和打包入口；单一版本来源；MIT 开源与第三方许可补齐；公开源码清单、Windows CI、Release 草稿流程和无个人数据的便携包。

修复基础字面查找与中文词边界的组合语义、草稿持久化与清空、输入法开关、提交去重和焦点恢复。新增默认开启的系统通知开关；开启时提交复制成功统一发通知，关闭时保持复制与提交行为。胶囊提示粘贴/仅复制路由，保留成熟毛玻璃、主题和设置。

更新应用图标并统一程序文件、托盘和编辑窗口的资源；中英文 README 增加中英混排、Vim 入门、外观调整与通知设置示例。

已测试大量 Windows 应用，Microsoft To Do 已确认修复。Windows 任务栏搜索和微信为已知不可自动回填项，使用剪贴板手动粘贴；真实输入法、多屏 DPI 和其他应用继续验收。
