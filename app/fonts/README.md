# Sarasa Mono SC

Bundled `SarasaMonoSC-Regular.ttf`, release v1.0.42, extracted from the official `SarasaMonoSC-TTF-1.0.42.7z` asset. SHA-256: `82E09460F6F55010296F670B85E346DDEAF91B967724840D2BF5514137F68A83`. Licensed under SIL Open Font License 1.1; see [OFL-1.1.txt](OFL-1.1.txt).

The current Neovide build includes Sarasa Mono SC in its font fallback list for Chinese text. System Consolas is preferred for Latin text; Consolas and Microsoft YaHei UI are loaded from Windows and are not redistributed with PinyinVim. Font selection is configured through Neovim's `guifont` setting.
