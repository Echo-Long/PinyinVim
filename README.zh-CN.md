<h1 align="center">拼音浮笺 · PinyinVim</h1>

<p align="center">随手呼出，用 Vim 舒适地编辑中文。</p>
<p align="center"><a href="README.md">English</a> · <strong>简体中文</strong></p>

在独立浮窗里专心写作，用熟悉的 Vim 动作编辑，再把文字带回原来的应用。拼音浮笺使用真实 Neovim 编辑内核，加入本地中文导航，配合毛玻璃界面和可自定义的主题。

> **运行平台：**Windows x64，应用界面为简体中文。产品版本统一定义在 [package.json](package.json)。

[快速上手](#开始使用) · [中英混排](#中文增强与-vim-操作) · [Vim 入门](#vim-入门) · [调整界面](#调整界面) · [通知开关](#系统通知) · [应用适配](#提交文字与应用适配)

## 能做什么

- **使用真实 Vim 编辑。** Normal、Insert、Visual 模式，以及操作符、寄存器、宏、撤销和重复动作，由 Neovim 提供。
- **顺畅编辑中英混排。** 字符查找保留英文字母的字面匹配，小写字母额外匹配中文拼音首字母；中文词语导航沿用熟悉的移动命令和文本对象。
- **随时续写草稿。** 用全局快捷键呼出浮窗，暂时不用时收起；编辑期间自动保存，下次打开继续写。
- **调整自己的界面。** 十套主题色、浅色与深色模式、背景图片、模糊程度，以及外壳和胶囊面板各自的透明度。
- **按编辑模式切换输入法。** 记录 Insert 模式下的输入法状态，Normal、Visual 模式使用英文，再回到 Insert 时恢复之前的状态；可在设置中关闭此策略。
- **复制或回填文字。** 能确认原输入框时尝试一次粘贴；其他情况保留在剪贴板，便于手动粘贴。复制结果通知可自行开启或关闭。

中文导航在本地处理。编辑期间不调用 AI 服务，也不上传草稿正文。

## 开始使用

从 [Releases](https://github.com/Echo-Long/PinyinVim/releases) 下载 Windows x64 便携包。将**整个文件夹**解压到可写目录，打开 `PinyinVim.exe`。Neovim、Neovide、词典和备用字体随包附带，运行时无需安装 Node.js、Python 或独立的 Vim。

系统需要 .NET Framework 4.8、Microsoft Visual C++ v14 x64 运行库和可用的图形驱动。若启动提示缺少 `VCRUNTIME140.dll`，请查看[便携版说明](docs/portable-readme.md)，从[微软官方页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)获取对应运行库。发布准备期间，也可以[从源码构建](#从源码构建与测试)。

### 一分钟写好第一份草稿

1. 先在目标应用的输入框中放好光标，再按 `Ctrl+Shift+X` 呼出浮窗。
2. 按 `i` 进入 Insert 模式输入文字；按 `Esc` 回到 Normal 模式，使用 Vim 命令移动和编辑。
3. 按 `Ctrl+Enter` 提交。适配的输入框会尝试回填一次；仅剪贴板模式下，切回需要输入的位置，自行按 `Ctrl+V` 粘贴。

暂时不提交时，在 Normal 模式按 `Esc` 收起，下次继续写。按 `F2` 打开设置，修改会自动保存并应用。

### 默认快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+X` | 呼出或收起浮动编辑器。 |
| `i` | 从 Normal 模式进入 Insert，开始输入。 |
| `Esc` | 在 Insert、Visual 或命令行中保持 Vim 原生退出/取消语义；回到 Normal 后再按一次，收起窗口。 |
| `Ctrl+Enter` | 提交草稿：尝试粘贴到原输入框，或复制后手动粘贴。 |
| `F2` | 打开设置。 |
| `Ctrl+C` | Normal、Insert 模式复制整份草稿；Visual 模式复制选区。 |
| `Ctrl+V` | 在 Insert 模式粘贴剪贴板文字。 |
| `Ctrl+鼠标滚轮` | 调整编辑字号。 |

应用快捷键可以在设置中修改，在生效的模式中优先于原有 Vim 绑定。关闭窗口、`Alt+F4` 和最小化也会收起编辑器。真正结束程序请使用系统托盘菜单中的**退出**。

## 中文增强与 Vim 操作

在 `F2 → 编辑与草稿` 中开启“拼音首字母定位”和“中文分词导览”。两个开关可以分别控制。

### 试试中英混排

将下面一行放入草稿，按 `Esc` 回到 Normal 模式，再依次尝试表中的命令。每条命令都以 `0` 开头，先回到行首。

`0` 是 Vim 的“回到当前行第一个字符”命令，包含行首空格。例如，`0fr` 就是依次按 `0`、`f`、`r`；`02fm` 则是先回到行首，再用 `2fm` 查找第二个匹配 `m` 的位置。

```text
今天 review 中文，明天 merge 项目。
```

| 输入命令 | 效果 |
| --- | --- |
| `0fr` | 跳到 `review` 中的英文字母 `r`，保留原生字符匹配。 |
| `0fz` | 跳到“中”，因为它的拼音首字母是 `z`。 |
| `0fm` | 跳到“明”，它是前方第一个匹配 `m` 的位置。 |
| `02fm` | 跳到 `merge` 中的英文 `m`，它是第二个匹配；英文与中文匹配共同计数。 |

查找范围仍是当前行。小写英文字母同时匹配字面字符与中文拼音首字母；大写目标只做字面匹配。查找后按 `;` 沿原方向重复，按 `,` 沿反方向重复。

### 熟悉的动作，按中文词语操作

| 编辑动作 | 怎么用 |
| --- | --- |
| `f` / `F` | 在当前行向前/向后查找字符。 |
| `t` / `T` | 停在对应目标前/后一个位置，可与 `d`、`c` 等操作符组合。 |
| `w` / `b` | 移动到下一个/上一个词的边界，支持中文词语。 |
| `e` / `ge` | 移动到当前或下一个词的末尾 / 上一个词的末尾。 |
| `ciw` | 光标放在词语上，修改这个词，并进入 Insert 模式。 |
| `diw` / `daw` | 删除词内文字 / 删除词语及相应周围空格。 |
| `viw` | 在 Visual 模式选中当前词语。 |
| `3w` | 连续移动三个词；字符查找和操作符也支持计数。 |

例如，把光标移到示例中的“项目”，输入 `ciw`，即可直接替换这个词。词边界由随附的本地词典识别，标点单独作为边界；关闭中文增强开关后，相应动作恢复原生行为。

正文、撤销和命令模型继续使用 Neovim 的现有实现；纯英文动作和操作符通过与原生 Neovim 的差分测试检查。

## Vim 入门

刚接触 Vim 时，先掌握下面这些操作。需要输入 Normal 模式命令时，先按 `Esc`。

| 想做什么 | 按键 |
| --- | --- |
| 开始输入 / 回到 Normal 模式 | `i` / `Esc` |
| 向左、下、上、右移动 | `h`、`j`、`k`、`l` |
| 到行首 / 行尾 | `0` / `$` |
| 选择文字 | `v` 后移动光标；`V` 按整行选择。 |
| 复制一行 / 粘贴 Vim 寄存器内容 | `yy` / `p` |
| 删除一行 | `dd` |
| 撤销 / 重做 | `u` / `Ctrl+R` |
| 重复上一次修改 | `.` |
| 搜索文字 / 下一个结果 | `/文字`、`Enter` / `n` |

需要复制到 Windows 剪贴板时用 `Ctrl+C`；`yy` 和 `p` 使用 Vim 寄存器。应用快捷键只在其生效模式中覆盖对应的原生绑定。

## 调整界面

按 `F2 → 外观` 打开设置，修改立即应用并自动保存。

| 设置 | 怎么调整 |
| --- | --- |
| **主题色** | 在雾蓝、柠檬黄、薰衣草、薄荷绿、蜜桃、玫瑰、晴空蓝、砂岩、森林、石墨十套配色中选择，改变外壳与胶囊的颜色。 |
| **深色主题** | 切换编辑区的浅色或深色配色。 |
| **背景模糊（毛玻璃）** | 开启磨砂背景，再用“高斯模糊”调整模糊程度。 |
| **背景透明度** | 决定外壳透出多少背景。`0%` 不透明，`100%` 完全透明。 |
| **胶囊透明度** | 单独调整编辑区、消息区和小胶囊面板，和外壳背景分开控制。 |
| **背景图片** | 点击“选择”打开本地图片，图片铺满窗口并遵循背景透明度；点击“清除”移除图片。可先使用 PNG/JPG，选择框也接受 WEBP；无法读取的图片自动回退为普通背景。 |
| **编辑字号** | 在设置中修改，或在编辑器中使用 `Ctrl+鼠标滚轮`。 |

第一次体验毛玻璃，可以先用默认配置：雾蓝、开启毛玻璃、背景透明度 `50%`、胶囊透明度 `20%`、模糊半径 `5px`。使用背景图时，如果图片太淡，可降低背景透明度；希望文字背后的面板更实一些，则降低胶囊透明度。文字透明度单独保持，不会随背景一起变淡。“恢复默认外观”可以重置外观设置。

拖动外壳空白处移动窗口；拖动四边或四角缩放。

## 系统通知

在 `F2 → 编辑与草稿` 中开启或关闭“系统通知”。它**默认开启**，修改立即生效，重启后保留。

开启时，复制成功、非空提交结果以及启动状态会请求显示系统通知。关闭后不弹出这些系统通知；复制、粘贴和草稿自动保存仍照常执行，编辑器内的提示仍会显示。

Windows 自身的通知设置也可能影响通知展示。

## 提交文字与应用适配

我们已对大量 Windows 应用进行测试。在目标输入框中呼出拼音浮笺、写好后提交；能够识别并复验原输入框时，程序恢复焦点并尝试**一次**粘贴。提交按钮的悬浮提示会显示当前是回填还是仅复制。

### 已知不可自动回填项

| 应用或入口 | 使用方式 |
| --- | --- |
| **Windows 任务栏搜索** | 提交后文字进入剪贴板；必要时重新打开搜索框，按 `Ctrl+V` 手动粘贴。 |
| **微信** | 提交后文字进入剪贴板；切回聊天输入框，按 `Ctrl+V` 手动粘贴。 |

以上两项目前只能通过剪贴板手动粘贴。Microsoft To Do 原输入框焦点丢失的问题已修复并经实测确认。应用版本、权限和输入控件会影响适配；其他输入框无法确认时，也会退回剪贴板方式。

每次成功提交的非空文字都会进入剪贴板。**开启系统通知时**，通知会说明是否已发送粘贴，或需要手动粘贴。“已发送粘贴”只表示粘贴快捷键已发出，不能证明目标应用已接收文字。

程序不会向目标应用发送 `Enter`、自动发送聊天消息或重复尝试粘贴。提交文字会继续保留在剪贴板，目前不恢复之前的剪贴板内容。其他限制见[兼容说明](docs/compatibility.md)。

## 草稿、设置与隐私

首次启动后，会在程序旁创建 `prototype-profile`，保存配置与草稿。编辑期间自动保存；收起窗口保留草稿。“退出时清空草稿”仅在从托盘菜单退出程序时生效；关闭该选项后，退出也保留草稿。成功发送粘贴后，下一次呼出会准备新草稿，上一份提交保存在 `prototype-profile/last-submitted.txt`，可用于恢复；仅复制或提交失败时保留当前草稿。

升级前先保存需要的文字、退出旧实例，再将新版放到独立目录；迁移方法见[便携版说明](docs/portable-readme.md)。草稿和配置可能包含个人信息，请不要将它们提交到公开仓库或附在问题报告中。

目标输入框识别只检查焦点、控件能力以及窗口/进程身份，不读取目标应用的正文；适配诊断记录进程名、控件类型和结果，不记录草稿正文。

## 从源码构建与测试

开发环境为 Windows x64，需要 Windows PowerShell 5.1 或 PowerShell 7、系统 .NET Framework 编译器，以及 `PATH` 中的 MinGW-w64 `gcc`。环境准备和运行时校验方式见[构建说明](docs/build.md)。

```powershell
# 下载并校验固定版本的 Neovim、Neovide。
.\native\setup-runtime.ps1

# 构建应用，再运行自动检查。
.\native\build.ps1
.\native\test.ps1

# 打开已有构建。
.\native\start.ps1
```

安装了 Node.js 时，也可以使用 `npm run build`、`npm test` 和 `npm start`。日常构建使用源码中已有词典，不需要安装 npm 依赖；重新生成词典时，需要 Node.js 20+、`npm ci`，再运行 `npm run data:regenerate`。

构建从 `package.json` 生成产品版本信息；第三方运行时的固定版本与校验值位于 [native/runtime-assets.json](native/runtime-assets.json)。自动检查覆盖原生 Vim 等价性、中文导航、草稿持久化、提交、焦点策略和设置合同；真实输入法、多屏 DPI、图形效果及外部应用接收文字仍需桌面实测。
