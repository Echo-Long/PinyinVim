# 产品路线

编辑内核使用 Neovim，窗口与绘制使用 Neovide，中文查找/词边界由已有插件适配层实现。Windows 宿主负责唤起、目标识别、一次回填、草稿、设置、通知及拥有进程的生命周期。继续复用现有内核、渲染和词典，不引入第二套正文或撤销模型。

当前版本完成基础 Vim/中文增强回归、草稿持久化、输入法策略、提交去重、焦点恢复、主题/毛玻璃以及发布流程收敛。版本信息只由 package.json 生成；源码与便携包分别发布。

后续优先完成真实微软拼音组合输入、多屏 DPI 和应用兼容矩阵。微信专用适配先调查 MSAA/LegacyIAccessible 能否提供焦点、可写/密码状态和稳定控件身份；无法确认时继续复制回退。控件重建后的再次定位、DirectText、原剪贴板恢复和真正 TSF 输入法均需独立验证与规划，不通过猜测控件或重复发送输入实现。
